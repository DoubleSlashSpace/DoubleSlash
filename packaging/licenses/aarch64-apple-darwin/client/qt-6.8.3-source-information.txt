Qt 6.8.3 — source and license information (macOS app bundle)
============================================================

What is shipped
---------------
The DoubleSlash macOS .app ships the Qt 6.8.3 runtime as frameworks
(QtCore.framework, QtGui.framework, QtQuick.framework and the other Qt
modules) together with the Qt plugin and QML module trees, deployed by
macdeployqt into Contents/Frameworks and Contents/PlugIns.

This build is configured with the `qt-ui` feature only. Qt WebEngine is **not**
included, so no Chromium snapshot ships in this bundle.

is retained in the project's evidence directory.

Provenance — unmodified upstream
--------------------------------
Qt is used as supplied by The Qt Company for macOS arm64 and is not modified
by DoubleSlash. No patch is applied to any Qt module and no Qt source file is
recompiled as part of the DoubleSlash build. The project's only vendored
patches apply to the Rust crates `cpal` and `wayland-scanner`, neither of which
is part of Qt. There are therefore no modifications to Qt to disclose.

Corresponding source
--------------------
Complete corresponding source for Qt 6.8.3 is published by The Qt Company:

  https://download.qt.io/archive/qt/6.8/6.8.3/single/
  https://code.qt.io/cgit/qt/qt5.git/  (tag v6.8.3)

DoubleSlash's own sources and its modified local dependencies are published at
https://github.com/DoubleSlashSpace/DoubleSlash; the notices name the exact
revision each build came from. They do not contain Qt sources, which are
obtained from the upstream locations above.

How the LGPL-3.0 obligations are met
------------------------------------
* Notice — the application's Settings > About > Third-Party Notices screen
  states that DoubleSlash uses Qt under the LGPL-3.0 and displays this text
  and the full licence. The same files ship under
  Contents/Resources/licenses/client/supplement/ inside the .app bundle.
* Licence text — qt-6.8.3-LGPL-3.0.txt accompanies the distribution.
* Source availability — the upstream locations above are published in the
  notices screen and in this file.
* Relinking — Qt is dynamically linked. Each Qt module is a separate
  framework inside the bundle and none is statically linked into the DoubleSlash
  binary. See relinking-instructions.txt for the procedure.
* No modifications — as recorded above, Qt is shipped unmodified.
