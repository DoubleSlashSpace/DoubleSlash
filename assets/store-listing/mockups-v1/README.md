# DoubleSlash promotional mockups

Three AI-generated promotional previews made with the built-in image generation
tool. Names, messages, files, room membership and video participants are fictional.
Each image is visibly labelled "Illustrative preview - Demo content" (with a
bullet separator in the artwork). These are not captures of an installed app and
do not establish acceptance testing or exact UI fidelity. Use an actual capture
of the shipping application for the required Microsoft Store screenshot.

- `01-invite-only-chat.png`: direct messages and a file attachment.
- `02-shared-rooms.png`: room text with voice and text-only membership in the tree.
- `03-calls-and-screen-sharing.png`: direct call with a fictional shared screen.

The exact generation and refinement prompts are in [prompts.json](prompts.json).
Generated originals remain in Codex's generated_images directory. These copies
are the project deliverables; no existing logo, UI code or Store package changed.
